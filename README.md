> [!WARNING]
>
> ### Реакция антивирусов
> Антивирус может среагировать на WinDivert.  
> Этот компонент перехватывает и фильтрует трафик и необходим для работы zapret.
> WinDivert применяют как легальные, так и вредоносные программы; сам компонент вирусом не является.
>
> **Цитата из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Ряд антивирусов считает файлы WinDivert потенциально опасными или относит их к хакерским инструментам. В результате файл удаляется и отправляется в карантин. В названии детекта при этом обязательно встречается `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Добавьте папку с zapret в исключения антивируса либо выключите обнаружение PUA (потенциально нежелательных приложений). В Касперском, например, для этого есть параметр «Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда». Если вы уверенно настраиваете исключения, рекомендуется добавить их; если не вполне понимаете последствия, рекомендуется отключить обнаружение PUA.

## ⚙️ Использование

1. Настройте безопасный DNS (Secure DNS).
    * В Chrome включите «Использовать безопасный DNS» и выберите DNS-поставщика, отличного от «Поставщик по умолчанию».
    * В Firefox откройте «DNS через HTTPS», укажите режим «Персональный», выберите «Выбрать провайдера/поставщика» и вручную введите URL. Например, `https://dns.google/dns-query`: Cloudflare может быть заблокирован.
    * Windows 11 позволяет включить Secure DNS в параметрах системы; [инструкция здесь](https://remontka.pro/dns-over-https-windows-11/). Этот вариант рекомендуется для пользователей Windows 11.
    * На роутерах Keenetic включите параметр «Транзит запросов». Если он выключен, Secure DNS на компьютере может быть сложно настроить или использовать.

2. Загрузите ZIP- или RAR-архив с [последнего релиза](https://github.com/HeightAlbatross/zapret-discord-youtube/releases/latest).

3. Откройте свойства архива и отметьте «Разблокировать». Для архиваторов 7-Zip и PeaZip этот шаг не нужен.

4. Извлеките архив в каталог, путь к которому не содержит кириллицу или специальные символы.

5. Запустите подходящий файл.
    * Чтобы подобрать стратегию, откройте **`service.bat`** → `Run Tests` → `Standard tests` → `All configs`.
    * Для запуска при старте системы выберите **`service.bat`** → `Install Service` → нужную стратегию.

## ℹ️ Кратко о файлах

- [**`general.bat ...`**](./general.bat) — запуск стратегии вручную.

  Такой запуск удобен для проверки разных вариантов. Результат зависит от многих условий, поэтому переберите стратегии, в том числе **ALT**, **FAKE** и другие, пока не найдёте работающую у вас.

- [**`service.bat`**](./service.bat) — управление автозапуском и дополнительные инструменты:
  - <ins>**`Install Service`** — добавить выбранную стратегию в автозапуск через services.msc.</ins>
  - **`Remove Services`** — удалить стратегию и WinDivert из служб.
  - **`Check Status`** — посмотреть состояние обхода и служб, включая стратегию автозапуска и WinDivert.
  - **`Game Filter`** — включить или выключить режим обхода для игр и других сервисов, использующих UDP и TCP на портах выше 1023.  
  После изменения режима перезапустите стратегию.  
  Текущее состояние (включено/выключено) показано в скобках.
  - **`IPSet Filter`** — настроить фильтрацию сервисов из `ipset-all.txt`. Этот режим полезен при проверке ресурса, который доступен без zapret, но не работает с ним.  
  Скобки показывают выбранный режим:
    - `none` — ни один IP не проверяется.
    - `loaded` — IP сопоставляются со списком.
    - `any` — фильтруется любой IP.
  - **`Auto-Update Check`** — включить или отключить автоматическую проверку обновлений.
  - **`Replace active fakes`** — подставить вместо выбранного фейка другой файл из `bin`.
  - **`Update IPSet List`** — загрузить актуальный `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** — обновить hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>.
  - **`Check for Updates`** — проверить наличие обновлений.
  - **`Run Diagnostics`** — проверить типичные причины сбоев zapret. В конце можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает, если приложение неожиданно перестало работать.
  - **`Run Tests`** — проверить работоспособность стратегий с помощью утилиты:
    - `Standard tests` — тестирование сайтов из `utils/targets.txt`.
    - `DPI checkers` — проверка DPI у разных провайдеров, включая Cloudflare и Amazon.

## ☑️ Частые вопросы и проблемы

### После запуска `general*` ничего не происходит

- При запуске стратегии отдельным BAT-файлом, а не через service, должен открыться winws.exe. Его значок можно увидеть на панели задач.  
Если окно или значок не появились, посмотрите [#522](https://github.com/HeightAlbatross/zapret-discord-youtube/issues/522).

### Не подходит ни одна стратегия
- Откройте командную строку с правами администратора.
- По очереди выполните команды:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`
  
- Перезагрузите компьютер.

### Не открывается веб-версия Telegram
Запустите **`service.bat`** и выберите **`Update hosts file`**. Если ваш hosts устарел, программа предложит обновить файл вручную:  
  - Скопируйте весь текст из открывшегося блокнота.
  - В появившейся папке откройте файл `hosts` текстовым редактором, запущенным от имени администратора.
  - Вставьте скопированный текст в конец файла `hosts`. Если вы уже добавляли аналогичные записи, замените их.
  - Сохраните файл и проверьте соединение ещё раз. Если проблема осталась, убедитесь, что изменения в `hosts` действительно сохранились.

#### Работа не гарантируется. Если это не помогло, воспользуйтесь [Telegram Desktop](https://github.com/telegramdesktop/tdesktop/releases) вместе с [локальным прокси](https://github.com/HeightAlbatross/tg-ws-proxy) или любым публичным прокси.

### Обход не работает или перестал помогать

> [!IMPORTANT]
> **Со временем отдельные стратегии могут перестать работать.**
> Стратегия может какое-то время обходить обнаружение, а затем перестать.
> В репозитории есть несколько стратегий. Если ни одна вам не подходит, потребуется создать свою: возьмите имеющийся вариант за основу и измените его параметры.
> Описание параметров приведено [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- В `service.bat` откройте `Run Diagnostics` и проверьте, нет ли ошибок.

- Убедитесь, что адрес нужного ресурса внесён в список доменов или IP-адресов.

- Проверьте другие варианты, например **`ALT`** и **`FAKE`**.

- При необходимости полностью переустановите программу по инструкции ниже.

- См. [#765](https://github.com/HeightAlbatross/zapret-discord-youtube/issues/765).

### Как выполнить полную переустановку или обновление?
- Сохраните добавленные вами данные и ресурсы.
- Перезагрузите устройство.
- Откройте `service.bat` → `Remove Services`.
- Выберите в `service.bat` пункт `Run Diagnostics`; исправьте найденные ошибки, а в конце ответьте Y.
- Удалите папку zapret.
- Скачайте свежую версию (`zapret-discord-youtube-...`) со [страницы релизов](https://github.com/HeightAlbatross/zapret-discord-youtube/releases).
- Щёлкните архив правой кнопкой мыши и откройте свойства. Если справа внизу доступна галочка «Разблокировать», отметьте её, затем нажмите «Применить» и «ОК».
- Распакуйте архив в новую папку в корне диска; путь не должен содержать пробелы и специальные символы.
- По очереди запускайте различные `general`-скрипты и проверяйте доступность ресурсов. Если выбранный вариант не подходит, закройте программу значком замка на панели задач и запустите следующую стратегию.
- Когда найдёте рабочий вариант, добавьте его в автозапуск через `service.bat` → `Install Service`.

### Игра или приложение не работает при включённом zapret

- Проверьте в `service.bat`, что для `Game Filter` указано **`disabled`**, а для `IPSet Filter` — **`none`**. Другие значения могут ограничить доступ к ресурсам, на которые вы не рассчитывали.

### Античит сообщает о WinDivert

- Следуйте [этой инструкции](https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide).

### В Windows 7 требуется цифровая подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### WinDivert остаётся в службах после удаления через [**`service.bat`**](./service.bat)

1. В командной строке Windows (Win+R, затем `cmd`) узнайте имя службы:

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите её, подставив вместо `название_из_первого_шага` найденное имя:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, что настроен [Secure DNS](#%EF%B8%8Fиспользование).
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Если раньше всё работало, проверьте остальные стратегии.
- Дополнительная информация: [#251](https://github.com/HeightAlbatross/zapret-discord-youtube/discussions/251).

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что включён [Secure DNS](#%EF%B8%8Fиспользование).
- Сначала выясните, какая стратегия позволяет открыть YouTube, и запустите её.
- В `service.bat` выберите `Run Diagnostics` и очистите кэш Discord.
- Проверьте, заработало ли приложение после очистки кэша.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно пользоваться ей.
- Если Discord не работает и в браузере, переберите стратегии ещё раз: YouTube и Discord могут открываться при разных вариантах.
- Дополнительная информация: [#252](https://github.com/HeightAlbatross/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/HeightAlbatross/tg-ws-proxy).
- Также можно воспользоваться бесплатными MTProto-прокси из интернета.

### Не работают игры

Игры разные, поэтому исследовать и устранять неполадки в каждой из них невозможно.

Как правило, стоит сделать следующее:
- Через `service.bat` обновите ipset и включите `Game Filter`.
- Если результата нет, включите также `ipset any`.

Учтите, что с `ipset any` многие сайты могут перестать открываться. Не оставляйте этот режим включённым постоянно. Вместо этого выясните IP-адреса, которые использует игра, и добавьте их в `ipset-all.txt`.

Если проблему решить не удалось, откройте обсуждение в разделе [Discussions](https://github.com/HeightAlbatross/zapret-discord-youtube/discussions), а не в issues, и дождитесь ответа других игроков.

### Здесь нет описания моей проблемы

- Создайте [новое обращение](https://github.com/HeightAlbatross/zapret-discord-youtube/issues).

## 🗒️ Добавление адресов других ресурсов

Добавляйте адреса для обхода в соответствующие списки:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически.
- **`list-exclude-user.txt`** — домены-исключения. Например, сюда можно внести домен из сети, IP которой есть в `ipset-all.txt`, если сам домен фильтровать не нужно.
- **`ipset-all.txt`** — IP-адреса и подсети.
- **`ipset-exclude-user.txt`** — исключения для IP-адресов и подсетей.
  - Файлы **`*-user.txt`** появятся автоматически при первом запуске `zapret` или `service.bat`.
